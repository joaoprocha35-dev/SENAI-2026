🚀 SENAI 2026 - Desenvolvimento de Aplicativos Móveis

Este repositório foi criado durante as aulas no **SENAI (Turma 2026)** para centralizar e organizar os projetos e estudos de desenvolvimento de software, com foco principal no ecossistema Full Stack para dispositivos móveis.

Dentro deste diretório, especificamente na pasta `aplicativo-movel/app-novo`, encontra-se o desenvolvimento de um aplicativos móveis completo utilizando tecnologias modernas e robustas de mercado.

---

## 🛠️ Tecnologias Utilizadas nos Projetos

O aplicativo principal foi estruturado utilizando a stack de React Native para Front-End e node.js para Backend, integrada a um banco de dados relacional:

### **Front-end / Mobile**
* **React Native:** Framework para construção de aplicativos nativos tanto para Android quanto para iOS utilizando uma única base de código.
* **Expo:** Plataforma e ferramenta que facilita o desenvolvimento, teste e deploy do aplicativo móvel de forma rápida e eficiente.

### **Back-end / API**
* **Node.js:** Ambiente de execução JavaScript no servidor utilizado para construir uma API estável e escalável.
* **Express:** Framework minimalista para Node.js focado na estruturação de rotas, requisições (HTTP) e middlewares da aplicação.

### **Banco de Dados**
* **MySQL:** Sistema de gerenciamento de banco de dados relacional (SGBD) utilizado para persistir e estruturar todas as informações coletadas pelo aplicativo móvel.

## 🏫 Contexto de Aprendizado (SENAI)

Os códigos contidos nesta pasta representam a aplicação prática de conceitos teóricos fundamentais do desenvolvimento de software, incluindo:
* Arquitetura de software no modelo **Cliente-Servidor**.
* Construção de **APIs RESTful** estruturadas com os métodos HTTP (`GET`, `POST`, `PUT`, `DELETE`).
* Gerenciamento de estados e navegação fluida em interfaces mobile.
* Modelagem de dados, criação de tabelas e execução de consultas SQL nativas.
* Versionamento de código profissional utilizando **Git** e hospedagem no **GitHub**.
