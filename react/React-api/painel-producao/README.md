# ⚙️ Gestão de Tarefas da Fábrica (CRUD API) - SENAI

Atividade desenvolvida no curso do SENAI para praticar a integração completa de rotas HTTP (GET, POST, PUT, PATCH e DELETE) em uma aplicação React estilizada com Bootstrap e CSS customizado.

## 🚀 Tecnologias Utilizadas
- **React** (`useState`, `useEffect`)
- **Bootstrap** (layout responsivo e formulários)
- **Fetch API** (manipulação de dados assíncronos)
- **JSONPlaceholder** (API fake para testes de requisições)

## 🎯 Funcionalidades
- **Listar (`GET`):** Carregamento das tarefas enviadas pela API ao abrir o sistema.
- **Cadastrar (`POST`):** Inserção de uma nova tarefa no topo da lista.
- **Atualização Parcial (`PATCH`):** Alterna o status da tarefa entre "Concluída" e "Pendente".
- **Substituição Completa (`PUT`):** Edição do nome da tarefa substituindo todo o objeto.
- **Remoção (`DELETE`):** Exclusão imediata da tarefa na lista.
