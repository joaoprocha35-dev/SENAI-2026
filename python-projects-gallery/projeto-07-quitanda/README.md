📖 Sobre o Projeto

O Quitanda do Tomate Cru é uma aplicação web desenvolvida para auxiliar no gerenciamento de produtos de uma quitanda ou hortifrúti.

O sistema permite realizar um CRUD completo (Create, Read, Update e Delete) de produtos através de uma API REST construída com Flask, integrada a um banco de dados MySQL.

Além disso, conta com um painel administrativo moderno, responsivo e intuitivo para facilitar o gerenciamento do estoque.

Principais Funcionalidades

✅ Cadastro de produtos

✅ Listagem de produtos em tempo real

✅ Atualização de informações

✅ Exclusão de registros

✅ Integração com banco MySQL

✅ API RESTful

✅ Interface responsiva com Bootstrap

✅ Comunicação Front-end ↔ Back-end via Fetch API
